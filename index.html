GUIDED LESSON

01. What is a VPC?

01 / 08

Amazon Virtual Private Cloud (Amazon VPC) lets you provision a logically isolated section of the AWS Cloud. You control the IP address range, subnets, route tables, and network gateways.

✦
Remember this

A VPC is your private network boundary inside AWS—not a physical data center.

CLI QUICK REFERENCE

Inspect a VPC from AWS CLI

aws ec2 describe-vpcs --query "Vpcs[*].[VpcId,CidrBlock,State]" --output table

Run this only after configuring AWS CLI credentials and a region. The command reads VPC details; it does not create or change resources.
